# Field Training Management System

A web-based system designed to simplify and organize the field training process for students, supervisors, and training institutions.

## 📌 About the Project

The **Field Training Management System** provides a centralized platform for managing student training requests, registrations, supervisors, and training information.

The system aims to reduce manual work and make the training process more organized, accessible, and efficient.

## ✨ Features

* 👩‍🎓 Student training registration
* 🏢 Training institution management
* 👨‍🏫 Supervisor management
* 📝 Training request submission and management
* 📊 Student training information tracking
* 🔐 User authentication and role-based access
* 💾 Database management for training records
* 📱 Responsive web interface

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **PHP**
* **MySQL**
* **XAMPP**

## 👥 System Roles

The system supports different users, including:

* **Students** — Submit and manage training requests and information.
* **Supervisors** — Follow up with students and manage training-related information.
* **Institutions** — Provide and manage training opportunities.
* **Administrators** — Manage users and system data.

## 🎯 Project Goal

The main goal of this project is to create a simple and organized digital solution for managing field training and connecting students with supervisors and training institutions.

## 🚀 Getting Started

### Requirements

Make sure you have installed:

* XAMPP
* PHP 8+
* MySQL
* A modern web browser

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/lailahamoudah53-source/Field-Training-Management-System-.git
   ```

2. Move the project folder into the XAMPP `htdocs` directory.

3. Start **Apache** and **MySQL** from XAMPP.

4. Create the project database in **phpMyAdmin**.

5. Import the provided SQL database file.

6. Update the database connection settings if needed.

7. Open the project in your browser:

   ```text
   http://localhost/Field-Training-Management-System-
   ```
